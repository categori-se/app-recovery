# app-recovery

Reusable POSIX filesystem, checkpoint and local Git recovery mechanics.

Alpha source bundle v0.1.0-alpha.3; Apache-2.0. Not for production use.

- [project-recovery-core](recovery_core/README.md): 0.1.0a3

Bundle tags identify the combined source tree; package versions remain independent. Provider credentials, client data, hosted services and operating configuration are outside this release. No npm or PyPI publication is included.

Run the commands in `.github/workflows/test.yml` from the repository root. Tests use the standard library and synthetic fixtures.
